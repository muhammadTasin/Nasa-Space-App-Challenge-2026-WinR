# Project EDEN (Earth Data & Environment Navigator)
## UI Design Screens & Interactive Portfolio

এই ফোল্ডারে **Project EDEN**-এর জন্য রিক্রিয়েট কৃত ৬টি ডেক্সটপ স্ক্রিন এবং ১টি ডেডিকেটেড পোর্ট্রেট অ্যান্ড্রয়েড মোবাইল স্ক্রিনের লাইভ HTML এবং হাই-রেজোলিউশন স্ক্রিনশট অন্তর্ভুক্ত রয়েছে।

### কীভাবে দেখবেন?
1. সরাসরি ব্রাউজারে দেখতে ফোল্ডারের `index.html` ফাইলটিতে ডাবল-ক্লিক করুন।
2. গ্যালারিতে লাইভ ইন্টারঅ্যাক্টিভ HTML এবং হাই-রেজোলিউশন ছবি উভয়ই সুইচ করে দেখা যাবে।
3. কী-বোর্ডের Arrow Keys (বাম / ডান) ব্যবহার করে সহজেই এক স্ক্রিন থেকে অন্য স্ক্রিনে যাওয়া যাবে।
